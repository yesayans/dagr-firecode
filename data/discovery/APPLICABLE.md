## How to regenerate

```bash
# All 395 packages with review counts
python scripts/list_applicable_apps.py --dataset sealuzh --min-reviews 1 --top 400

# Only apps with a GitHub mapping + live/cached roadmap stats
python scripts/list_applicable_apps.py --dataset sealuzh --min-reviews 100 --top 50 --only-github --check-github
```

Optional: set `GITHUB_TOKEN` env var to avoid API rate limits.
